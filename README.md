# PracticaEjerciciosPython_1

Repositorio de ejercicios prácticos en Python desarrollados como parte del proceso de aprendizaje en Riwi. Incluye 20 ejercicios de refuerzo organizados por niveles, un simulador de cajero automático y una herramienta de ventas funcional.


· 20 ejercicios de práctica organizados por niveles, desde lo más básico (input y print) hasta condicionales y operadores lógicos.
· Simulador de cajero automático donde se puede consultar saldo, retirar y depositar dinero.
· Herramienta de ventas para RiwiTechStore que registra una venta, aplica descuento VIP y muestra el resumen final.




¿Qué aprendí?

·Variables y tipos de datos
·Entrada y salida por consola
·Operadores aritméticos y lógicos
·Condicionales con if, elif y else
·Bucles con while

Python 3.x
No requiere librerías externas
